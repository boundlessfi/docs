# Technical integrations

### GitHub (developers)

* Link via OAuth.
* Verified developer badge.
* Support repo-based bounties.
* Auto-detect submissions from PR events.

### Wallet layer

* Passkey auth via WebAuthn.
* Stellar transactions.
* Soroban escrow contracts.

### KYC provider

* Hosted KYC flow.
* Webhooks for status updates.
* Only verification status is stored in Boundless.

### Notifications

* Email for payments and status changes.
* In-app notification center.
* Optional push.

### Public API (planned)

* Bounties.
* Applications.
* Users.
* Transactions.
* Webhooks for key events.
