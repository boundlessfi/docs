# Features by user type

{% tabs %}
{% tab title="Participants" %}
#### Discover

* Browse and filter active bounties.
* Save favorites.
* Set alerts for matching bounties.

#### Apply and deliver

* Submit proposals.
* Track application status.
* Upload deliverables.
* Request deadline extensions.

#### Profile

* Manage skills and portfolio.
* Link GitHub.
* Complete KYC.
* Set notification preferences.

#### Financial

* View balance and history.
* Send and receive XLM.
* Export transactions.
{% endtab %}

{% tab title="Projects" %}
#### Create bounties

* Draft bounties with rich descriptions.
* Choose a claiming model.
* Set budgets, milestones, and deadlines.
* Fund escrow.

#### Manage applicants

* Review applications side-by-side.
* Message candidates.
* Select winners.

#### Review work

* Provide feedback.
* Approve or reject submissions.
* Release payments from escrow.
* Rate contributors.

#### Analytics

* Application volume and quality.
* Completion rates and time-to-delivery.
* Budget usage.
{% endtab %}
{% endtabs %}
