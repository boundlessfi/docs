# Roadmap

### Phase 1 — MVP

* 4 claiming models.
* Passkey wallet.
* Spark Credits.
* Basic reputation.
* Lightning Rounds (manual curation).
* GitHub linking.
* Email notifications.

### Phase 2 — Enhanced

* KYC levels.
* Better search and filters.
* AI bounty recommendations.
* Messaging.
* Portfolio builder.
* Mobile apps.
* Lightning Round automation.

### Phase 3 — Financial

* Off-ramp (XLM → fiat).
* Multi-currency support.
* Split payments.
* Recurring bounties.
* Tax reporting.

### Phase 4 — Community

* Governance experiments.
* Peer review.
* Skill endorsements.
* Expanded referrals and ambassador program.

### Phase 5 — Scale

* White-label platforms.
* Enterprise support.
* Bulk import/export.
* Multi-chain expansion.
