# UI and UX principles

Boundless Bounty is designed for non-crypto-native users.

It should feel like a modern consumer app.

### Principles

* Simplicity. Few clicks to core actions.
* Clarity. Clear next steps.
* Accessibility. WCAG 2.1 AA targets.
* Responsiveness. Mobile-first.
* Speed. Fast loads and optimistic UI.

### Key UI elements

* Spark Credits balance.
* Reputation level.
* Wallet balance.
* Filters for skills, budget, model, deadlines.

### Key screens

* Bounty dashboard.
* Bounty details.
* Profile and portfolio.
* Wallet.

### Interaction notes

* Show clear success states.
* Prefer skeleton loading over spinners.
* Use subtle animations for credits and completions.
