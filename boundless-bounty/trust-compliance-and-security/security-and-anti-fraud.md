# Security and anti-fraud

Security is a product feature.

It protects contributors and sponsors.

### Account security

* Passkeys (WebAuthn).
* Device authorization tracking.
* Session controls.
* Login notifications.

### Transaction security

* Smart contract escrow.
* Optional multi-sig for large payouts.
* Confirmation prompts for sensitive actions.
* Rate limits on withdrawals.

### Anti-fraud controls

#### Sybil resistance

* KYC gates for higher-risk models.
* Reputation requirements for premium bounties.
* Pattern and device checks.

#### Plagiarism detection

* Writing similarity checks.
* Code similarity checks.
* Manual review and community reports.

#### Collusion prevention

* Blind submissions for competitions.
* Independent review for large bounties.
* On-chain logging of key actions.

### Incident response

* Freeze suspicious accounts.
* Investigate and notify impacted users.
* Publish a transparency summary.
