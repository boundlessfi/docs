# Contributor KYC and verification

KYC reduces fraud and enables fiat off-ramps.

It also supports premium work and dispute resolution.

### Verification levels

#### Level 0 — Unverified

* Access to basic bounties.
* Lower withdrawal limits.

#### Level 1 — Basic KYC

* Government ID and selfie check.
* Higher bounty access.
* Off-ramp access at smaller tiers.

#### Level 2 — Full KYC

* Enhanced checks like proof of address.
* Access to all bounties.
* Full off-ramp access.
* “Verified Professional” badge.

### Privacy

* KYC data is stored by the provider.
* Boundless receives only verification status.
* Users control what profile fields are public.
