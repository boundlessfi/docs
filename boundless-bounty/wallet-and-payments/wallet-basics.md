# Wallet basics

Boundless uses passkeys to create and secure wallets.

You authenticate with WebAuthn.

A Stellar account is created behind the scenes.

### What you can do

#### View balances

* XLM available.
* XLM locked in escrow.
* Total balance and USD equivalent.

#### Send XLM

* Send to any Stellar address.
* Use QR codes for addresses.
* Include memos when needed.

#### Receive XLM

* Share your Stellar address.
* Use a QR code.

#### Transaction history

* Filter by received, sent, bounty payments.
* Search by date and amount.
* Export CSV for accounting.

### Security defaults

* Passkey confirmation for sensitive actions.
* Device-bound credentials.
* Login notifications.
