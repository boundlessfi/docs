# User journeys

{% tabs %}
{% tab title="Participant" %}
{% stepper %}
{% step %}
### Sign up

* Open `bounty.boundlessfi.xyz`.
* Create a passkey.
* Get a Stellar wallet automatically.
{% endstep %}

{% step %}
### Set up your profile

* Add name and username.
* Select skills.
* Add optional social links.
* Link GitHub if you’re a developer.
{% endstep %}

{% step %}
### Apply or claim

* Pick a bounty.
* Confirm the model and Spark Credit cost.
* Submit an application or claim a slot.
{% endstep %}

{% step %}
### Deliver and get reviewed

* Submit milestones or the final deliverable.
* Iterate on feedback if needed.
{% endstep %}

{% step %}
### Get paid and build reputation

* Approval releases XLM from escrow.
* Reputation updates based on quality and timeliness.
* Spark Credits restore when applicable.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Project" %}
{% stepper %}
{% step %}
### Create a project account

* Create a passkey.
* Add org or project details.
* Complete verification if you need higher limits.
{% endstep %}

{% step %}
### Create and fund a bounty

* Write the description and acceptance criteria.
* Choose the claiming model.
* Set budget and deadlines.
* Fund escrow in XLM.
{% endstep %}

{% step %}
### Review applications or submissions

* Compare applicants and reputation.
* Provide feedback on deliverables.
{% endstep %}

{% step %}
### Approve and pay

* Approval releases funds from escrow.
* Rate the contributor.
{% endstep %}

{% step %}
### Track performance

* Monitor completion rates.
* Track response time and contributor satisfaction.
* Review spend and ROI.
{% endstep %}
{% endstepper %}
{% endtab %}
{% endtabs %}
