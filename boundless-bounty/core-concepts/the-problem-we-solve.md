# The problem we solve

Most Web3 bounty platforms optimize for code-only work.

That leaves a big part of real project work unpaid.

### What breaks today

* **Non-dev talent gets excluded.** Designers, writers, marketers, researchers.
* **Skill recognition is too narrow.** Only commits and PRs count.
* **Onboarding is too technical.** Wallet setup and jargon block newcomers.
* **Spam overwhelms teams.** Low-effort applications drown out quality.
* **Models are inflexible.** One structure cannot fit every task.

### What Boundless changes

* **All skills welcome.** Explicit support for non-code work.
* **Spark Credits.** A simple “cost” to apply.
* **Four claiming models.** Single Claim, Application, Competition, Multi-Winner.
* **Passkey wallets.** Sign up with biometrics.
* **Reputation for every contribution.** Not just code.
