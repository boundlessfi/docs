# Choosing a model

Boundless supports four claiming models.

Each model trades off speed, quality assurance, and reviewer effort.

### Model summary

* **Single Claim:** First come, exclusive lock.
* **Application + Selection:** Proposals first. Creator selects one.
* **Competition:** Multiple submissions. Best wins.
* **Multi-Winner:** Milestones with multiple winners per stage.

### Quick guidance

* Use **Single Claim** for urgent, well-scoped tasks.
* Use **Application** when expertise matters and stakes are high.
* Use **Competition** for creative work and subjective outcomes.
* Use **Multi-Winner** for large work that splits naturally.

{% hint style="info" %}
Projects can combine models over time. Example: Multi-Winner milestones that end with a final competition stage.
{% endhint %}
