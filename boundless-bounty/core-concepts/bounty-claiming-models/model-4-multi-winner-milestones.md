# Model 4 — Multi-winner milestones

Large bounties can be split into milestones.

Each milestone can pay multiple winners.

### Best used for

* Large, complex initiatives.
* Work that splits by region, language, or component.
* Exploratory research.
* Resources that benefit from multiple perspectives.

### How milestones work

* Milestones define a deliverable and payout.
* Contributors apply for a specific milestone slot.
* Payment happens per milestone.
* Top performers can advance to later milestones.

### Advancement rules (examples)

* Minimum quality score.
* On-time delivery.
* Reviewer feedback.
* Top N evaluation scores.

### Escrow and payouts

* Total budget is escrowed up front.
* Each milestone pays on approval.
* Unused slots can refund back to the project.

{% hint style="info" %}
Multi-winner reduces wasted effort. It also scales reviewer load.
{% endhint %}
