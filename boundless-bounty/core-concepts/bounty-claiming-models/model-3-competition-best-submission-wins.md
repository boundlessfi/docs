# Model 3 — Competition (best submission wins)

Multiple contributors work in parallel.

Only the best submission wins.

### Best used for

* Design and branding.
* Naming and copy.
* Short, high-variance tasks.
* Cases where you want multiple options.

### Typical configuration

* Max competitors (common range: 3–5).
* Hard submission deadline.
* Reveal mode: blind reveal or rolling review.
* Optional consolation prizes for 2nd/3rd.

### Fairness rules

* Hide submissions until the deadline.
* Publish an evaluation rubric up front.
* Winner transfers IP for the winning work.
* Non-winners keep IP. Projects cannot use losing work.

{% hint style="warning" %}
Competitions create contributor risk. Use them only when multiple options matter.
{% endhint %}
