# Model 2 — Application + Selection

Contributors apply with a proposal.

The project selects the best candidate.

### Best used for

* High-value bounties.
* Research and analysis.
* Specialized expertise.
* Deliverables with high downside risk.

### What an application includes

* Relevant experience.
* Proposed approach.
* Timeline and milestones.
* Portfolio or samples.
* Answers to project questions.

### Configuration options

* Application window (fixed or manual close).
* Max applicants (common range: 5–10).
* Minimum requirements (reputation, samples, proposal length).

### Flow

1. Bounty opens for applications.
2. Contributor applies (Spark Credit is deducted).
3. Project reviews and selects one.
4. Selected contributor gets exclusive rights.
5. Work is delivered and reviewed.
6. Payment releases on approval.

{% hint style="info" %}
When you’re not selected, your Spark Credit can be restored. See [Spark Credits](../spark-credits.md).
{% endhint %}
