# Admin journey

Admins enforce quality and safety.

They also trigger escrow actions.

### 1) Dashboard

Monitor:

* Pending campaign reviews
* Active campaigns
* Pending milestone reviews
* Active disputes
* Platform health

### 2) Review campaigns

Check:

* Creator profile and history
* Milestone quality and measurability
* Goal reasonableness
* Supporting evidence
* Policy compliance

Decide:

* Approve → enters validation.
* Reject → send reasons + feedback.
* Revisions needed → send required changes.

### 3) Monitor active campaigns

Watch for:

* Misleading updates
* Backer complaints
* Suspicious activity

Possible interventions:

* Pause campaign
* Request clarification
* Escalate

### 4) Review milestones

Check:

* Deliverables and links
* Acceptance criteria
* Red flags (plagiarism, fabricated evidence)

Decide:

* Approve → release tranche.
* Reject → feedback + resubmission deadline.

### 5) Manage disputes

* Collect evidence from both sides.
* Mediate when possible.
* Escalate to TrustlessWork arbitration when needed.

Possible outcomes:

* Resubmission
* Partial refund
* Full refund
* Conditional approval
* Creator ban (severe)
