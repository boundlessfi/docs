# Backer journey

### 1) Discover

Browse by:

* Category
* Status (Voting, Active, Funded)
* Popularity
* Launch date

Filter by:

* Goal range
* Duration
* Creator reputation
* Milestone count

### 2) Evaluate

Review:

* Description and team
* Milestones and criteria
* Funding progress
* Comments and updates

### 3) Vote (pre-funding)

If in validation:

* Support, abstain, or flag concern.
* Leave feedback.
* Share to help reach threshold.

### 4) Pledge

* Pick amount (min **10 XLM**).
* Choose asset (XLM, USDC, EURC).
* Confirm escrow terms.
* Approve transaction with passkey.

### 5) Track delivery

Monitor:

* Active milestone
* Submission and review status
* Funds released
* Proof of work

### 6) Dispute (if needed)

If a milestone looks wrong:

* Signal dispute.
* Provide evidence.
* Participate in resolution.

### 7) Complete

After final approval:

* Review final deliverables.
* Rate the experience.
* Leave a testimonial.
