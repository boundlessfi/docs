# Community validation (voting)

Voting proves demand before funding opens.

It also filters spam.

### Purpose

* Gauge community interest.
* Surface high-quality campaigns.
* Build launch momentum.
* Reduce scams and low-effort submissions.
* Pressure-test milestone structure.

### Mechanics

#### Who can vote

* Verified Boundless users.
* One vote per user per campaign.
* Optional: reputation-weighted voting.

#### Vote options

* **Support**
* **Abstain**
* **Flag concern** (triggers admin attention)

#### Timing and threshold

* Voting period: **7–14 days**.
* Threshold: **100 support votes** (or weighted quorum).

### Dashboard

* Live vote count
* Threshold progress
* Time remaining
* Recent voters feed
* Comments + creator responses

### Outcomes

* Threshold reached → state becomes **Campaigning**.
* Threshold not reached → stays in validation.

### Editing during validation

* Minor edits allowed.
* Major changes reset voting.

Major changes include:

* Goal increase over **20%**
* Milestone structure changes
* Team member changes

Voters get notified on significant updates.
