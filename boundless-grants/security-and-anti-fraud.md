# Security and anti-fraud

Grants attract sybil and collusion attempts.

Controls need to be built-in.

### What to include

* Application fraud controls.
* Reviewer collusion mitigation.
* Identity and verification gates.
* Budget and payout safeguards.
* Audit logging.
