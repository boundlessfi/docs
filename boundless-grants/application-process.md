# Application process

Applications follow a predictable pipeline.

Programs define the exact requirements.

### Program discovery

1. Browse active programs on https://grants.boundlessfi.xyz.
2. Filter by category, budget, and deadline.
3. Subscribe to announcement emails.
4. Review requirements and evaluation criteria.
5. Check past awarded grants for reference.

### Application form

#### Project information

* Project title.
* One-sentence description.
* Detailed description (500–1000 words).
* Category.
* Target completion date.

#### Team

* Names and roles.
* Relevant experience.
* Past projects and GitHub profiles (dev grants).
* Publications or portfolio (research and content grants).

#### Technical details

* Technical approach or methodology.
* Architecture or research design.
* Stack or tools.
* Known challenges and mitigations.

#### Milestone breakdown

Define 2–6 milestones.

Each milestone includes:

* Description.
* Deliverables.
* % of total budget.
* Timeline.
* Acceptance criteria.

#### Budget

* Total requested amount (XLM).
* Budget justification.
* Breakdown by milestone.
* Other funding sources.

#### Impact

* Expected ecosystem benefit.
* Target users or audience.
* Success metrics.
* Long-term sustainability plan.

### Submission

1. Complete all required fields.
2. Upload supporting docs.
3. Review the preview.
4. Confirm the Stellar wallet address for receipts.
5. Submit the application.
6. Receive a confirmation email with an application ID.
7. Enter the review queue.

{% hint style="warning" %}
If your acceptance criteria are vague, milestone reviews get slow. Write criteria like test cases.
{% endhint %}
